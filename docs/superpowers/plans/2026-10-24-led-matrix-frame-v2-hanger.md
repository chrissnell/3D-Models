# led-matrix-frame-v2 Wall Hanger Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two new female socket knuckles to the side rails of `led-matrix-frame-v2` and a new printable "hanger" bar that snaps into them, enabling the frame to hang on a wall nail via a keyhole slot.

**Architecture:** All work happens in a single file, `led-matrix-frame-v2/led-matrix-frame-v2.scad`. New geometry is added in two parts: (1) a `_hanger_socket_knuckle(sx)` module invoked from `left_rail()` (the `right_rail()` mirror automatically produces the matching +X socket), and (2) a new printable part `hanger` (modeled in installed position by `hanger()` and bed-oriented by `printable_hanger()`). The Customizer `part = [...]` dropdown gets a new `hanger` entry so the existing `make` pipeline auto-discovers and exports it. Both the sockets and the hanger pins are driven from the SAME two parameters (`hanger_pin_axis_x`, `hanger_pin_axis_y`) so pin-to-socket spacing cannot drift. Alignment-critical invariants are enforced with `assert()` statements at the top of the file so a bad edit fails the render immediately.

**Tech Stack:** OpenSCAD (file is already using OpenSCAD 2021.01 syntax + the BOSL2 library it already includes), GNU Make for the build pipeline, bash scripts for parts enumeration and README regen.

**Reference spec:** `docs/superpowers/specs/2026-10-24-led-matrix-frame-v2-hanger-design.md`

**OpenSCAD on this machine:** The Makefile defaults `OPENSCAD` to `/Applications/OpenSCAD-2021.01.app/...` which does NOT exist on this machine. All `make` and `openscad` commands below set `OPENSCAD=/Applications/OpenSCAD.app/Contents/MacOS/OpenSCAD` explicitly. If the engineer is on a different machine, substitute the local path.

```openscad
// =====================================================================
// Hanger socket knuckle — one per side rail, sits on the inner wall of
// the rail. Same bell-curve silhouette as the corner knuckles. Socket
// is a thru-hole along Z; the matching pin on the hanger bar enters
// from -Z (back of frame). The knuckle is shifted forward (+Z) by
// `hanger_bar_t` so its socket mouth sits exactly at the bar's front
// face when the bar is flush with the rear of the frame.
//
// sx = -1 for left rail; the right-rail version is produced automatically
// by the existing `right_rail() { mirror([1,0,0]) left_rail(); }` call.
// =====================================================================
module _hanger_socket_knuckle(sx) {
    base_w = corner_knuckle_base_w;
    tip_w  = corner_knuckle_tip_w;
    kd     = corner_knuckle_depth;
    kn_t   = corner_knuckle_t;

    base_x = sx * inner_x;
    tip_x  = sx * (inner_x - kd);
    ax     = sx * hanger_pin_axis_x;
    ay     = hanger_pin_axis_y;

    z_bot  = -frame_depth + hanger_bar_t;
    z_top  = z_bot + kn_t;

    // Bell-curve polygon in X-Y, extruded in Z. Base on the rail's inner
    // wall (centered on ay in Y, width tapering from base_w to tip_w as
    // X moves from base_x to tip_x).
    bot = [
        for (i = [0 : ear_slices])
            let(frac = i / ear_slices,
                w    = tip_w + (base_w - tip_w) * (0.5 + 0.5 * cos(180 * frac)))
            [base_x + (tip_x - base_x) * frac, ay - w/2]
    ];
    top_rev = [
        for (i = [ear_slices : -1 : 0])
            let(frac = i / ear_slices,
                w    = tip_w + (base_w - tip_w) * (0.5 + 0.5 * cos(180 * frac)))
            [base_x + (tip_x - base_x) * frac, ay + w/2]
    ];

    difference() {
        translate([0, 0, z_bot])
            linear_extrude(height = z_top - z_bot)
                polygon(concat(bot, top_rev));
        // Thru-hole socket along Z. Oversize by 0.1 top & bottom for clean
        // boolean subtraction.
        translate([ax, ay, z_bot - 0.1])
            cylinder(d = corner_pin_d + 2 * corner_pin_tol,
                     h = (z_top - z_bot) + 0.2);
    }
}
```

## Task 3: Implement `hanger()` (installed-position module) and show it in the preview

Build the hanger bar in installed coordinates (same frame-space as the rails) and plug it into `assembled_preview()` so the `all` and `exploded` dropdown options show it in place. **Files:**
- Modify: `led-matrix-frame-v2/led-matrix-frame-v2.scad`

- [ ] **Step 1: Add the `hanger()` module (installed position, frame coords)**

Append this module immediately AFTER the stub `printable_hanger()` added in Task 1 (at the bottom of the file):

```openscad
// =====================================================================
// Hanger in installed position (same frame coords as the rails). Bar's
// back face sits flush with the frame rear at Z=-frame_depth; pins
// project forward (+Z) into the sockets. Used by assembled_preview()
// for the `all` and `exploded` dropdown views.
// =====================================================================
module hanger() {
    bar_z_bot = -frame_depth;
    bar_z_top = bar_z_bot + hanger_bar_t;
    pin_z_bot = bar_z_top;
    pin_z_top = pin_z_bot + corner_pin_len;

    difference() {
        union() {
            // Flat strap: X=[-apx, +apx], Y centered on hanger_pin_axis_y,
            // Z=[bar_z_bot, bar_z_top].
            translate([0, hanger_pin_axis_y, (bar_z_bot + bar_z_top) / 2])
                cube([2 * hanger_pin_axis_x, hanger_bar_w,
                      hanger_bar_t], center = true);
            // Two pins projecting forward from bar's front face.
            for (sx = [-1, 1])
                translate([sx * hanger_pin_axis_x, hanger_pin_axis_y, pin_z_bot])
                    cylinder(d = corner_pin_d, h = corner_pin_len);
        }
        // Keyhole slot (through the bar in Z). Round hole + rectangular
        // slot rising in +Y from the top of the round.
        translate([0, hanger_pin_axis_y, bar_z_bot - 0.1])
            cylinder(d = hanger_keyhole_round_d,
                     h = hanger_bar_t + 0.2);
        translate([0,
                   hanger_pin_axis_y + hanger_keyhole_round_d/2
                       + hanger_keyhole_slot_h/2,
                   bar_z_bot - 0.1])
            cube([hanger_keyhole_slot_w, hanger_keyhole_slot_h,
                  hanger_bar_t + 0.2], center = true);
    }
}
```

## Task 4: Replace the stub with real `printable_hanger()` (bed orientation + pin tip chamfer)

**Files:**
- Modify: `led-matrix-frame-v2/led-matrix-frame-v2.scad`

- [ ] **Step 1: Replace the stub `printable_hanger()` with the real one**

Replace the Task-1 stub body entirely. The new implementation reuses `hanger()` from Task 3 (DRY — pins, bar, keyhole all defined once in frame coords), applies the pin-tip chamfer by subtracting a conic frustum, and rotates for bed-friendly orientation.

Replace:

```openscad
module printable_hanger() {
    // STUB — replaced in Task 4. Visible placeholder cube.
    color("orange")
        cube([2 * hanger_pin_axis_x, hanger_bar_w, hanger_bar_t], center = true);
}
```

with:

```openscad
module printable_hanger() {
    // Take the installed-position hanger, apply pin-tip chamfers, then
    // flip for bed-friendly orientation. After the rotate+translate the
    // bar sits with its (originally) rear face on the bed (Z=0) and the
    // pins project upward in +Z on the printer.
    translate([0, -hanger_pin_axis_y, frame_depth])
        rotate([180, 0, 0])
            difference() {
                hanger();
                // Chamfer each pin tip (45°, hanger_pin_tip_chamfer deep).
                // The tip sits at Z = -frame_depth + hanger_bar_t + corner_pin_len.
                pin_tip_z = -frame_depth + hanger_bar_t + corner_pin_len;
                for (sx = [-1, 1])
                    translate([sx * hanger_pin_axis_x,
                               hanger_pin_axis_y,
                               pin_tip_z - hanger_pin_tip_chamfer])
                        difference() {
                            cylinder(d = corner_pin_d + 1,
                                     h = hanger_pin_tip_chamfer + 0.01);
                            cylinder(d1 = corner_pin_d
                                          - 2 * hanger_pin_tip_chamfer,
                                     d2 = corner_pin_d,
                                     h  = hanger_pin_tip_chamfer + 0.01);
                        }
            }
}
```
